Target board
ESP32-WROOM-32
Firmware
ESP32 Education Firmware v0.1.7
Installation method
Web Serial
Required browser
A browser with Web Serial support, such as Chrome or Edge
Install prebuilt firmware directly from your browser without setting up Arduino IDE or additional libraries.
For ESP32-WROOM-32 only. Do not install this firmware on XIAO ESP32-C3, ESP32-S3, or other boards.
Disconnect Arduino IDE’s Serial Monitor or ESP32 Education Editor first if either is using the ESP32 USB port.

Install Firmware

  1. Connect your ESP32-WROOM-32 to a PC or Chromebook via USB.
  2. Click the button below.
  3. Select the ESP32 USB serial port from the list.
  4. Follow the on-screen instructions to start installation.
This browser does not support Web Serial. Open this page in Chrome or Edge. This page must be opened over HTTPS or on localhost.

After Installation

Connect from ESP32 Education Editor and run SYS:STATUS. Check that the response includes SYS:READY:OK, the MAC address, and the current Wi-Fi channel.

v0.1.7

Supports USB / Web Serial, GPIO, DHT11 / DHT22, OLED, clearing a selected OLED area, HC-SR04 ultrasonic distance sensors, ESP-NOW, and servo control. Version 0.1.7 adds general-purpose PWM output and HC-SR04 support, and fixes an issue in Arduino-ESP32 3.x where PWM output could not resume after being stopped. BLE UART is not included in this version.
